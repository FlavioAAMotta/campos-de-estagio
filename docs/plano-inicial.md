# Preparação do repositório

Objetivo: entregar uma base React legível, navegável e pronta para receber a API
de cada grupo. A arquitetura está em [arquitetura.md](arquitetura.md).

1. Preservar o protótipo e os PDFs no primeiro commit.
2. Configurar React, Vite, lint e formatação; conferir o build e criar um commit
   com o ambiente mínimo funcionando.
3. Adaptar as telas para JSX, extrair os componentes e centralizar navegação,
   estilos e opções visuais. Conferir rotas e responsividade antes do commit.
4. Preparar configuração e cliente HTTP. Testar respostas JSON, texto, 204,
   erros, corpo de requisição e cancelamento antes do commit.
5. Documentar fork, instalação, arquitetura e integração. Adicionar verificação
   automática no GitHub e executar os mesmos comandos a partir do lockfile.

Cada commit deve descrever a mudança em português e agrupar apenas arquivos
necessários àquela entrega. O desenvolvimento acontece nesta pasta, conforme
solicitado, sem adicionar funcionalidades de negócio.
